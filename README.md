# Events API

REST API для управления мероприятиями на ASP.NET Core Web API (.NET 10).
Данные хранятся в памяти приложения. Для ручной проверки доступен Swagger UI.

## Требования

- .NET SDK 10

## Запуск

- Cкачать проект из репозитория или склонируйте его
- Запустить командную строку
- Выполнить команду cd <папка> для перехода в папку проекта
- Выполнить команду dotnet restore
- Выполнить команду dotnet build
- Выполнить команду dotnet run
- Откройте в браузере: http://localhost:5004/swagger/index.html

## API

| Метод | Путь | Описание | Ответы |
|-------|------|----------|--------|
| GET | `/events` | Список событий (по возрастанию `StartAt`, дополнительно по возрастанию `Id`) | 200 |
| GET | `/events/{id}` | Событие по id | 200, 404 |
| POST | `/events` | Создать событие | 201, 400 |
| PUT | `/events/{id}` | Обновить событие | 200, 400, 404 |
| DELETE | `/events/{id}` | Удалить событие | 200, 404 |

## Валидация

- `title` — обязательное, не пустое и не из одних пробелов, до 30 символов;
- `startAt`, `endAt` — обязательные;
- `endAt` должен быть позже `startAt`.

При нарушении — `400 Bad Request` с деталями.
